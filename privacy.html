Privacy policy

Last updated: 10 November 2026

What StoryBot is

StoryBot is a personal tool run by a single YouTube channel owner on their own computer. It generates short story videos and uploads them to that owner's channel. It has no other users.

Google data it accesses

StoryBot requests one permission: youtube.upload, which lets it upload videos to the signed-in channel. It does not request or read your profile, email, contacts, watch history, comments, or any other YouTube or Google data.

How that data is used and stored

  • The sign-in token Google issues is stored only in a local file on the owner's computer and is used only to upload the day's video.
  • No Google user data is sent to any server operated by StoryBot. StoryBot has no server.
  • No Google user data is sold, shared with third parties, or used for advertising.

Other services

Story text is generated with the Claude API by Anthropic, and narration is generated with Microsoft's text-to-speech voices. Neither service receives any Google user data.

Revoking access

Access can be removed at any time from your Google Account's third-party connections page. Deleting the local token file also stops all access.

Compliance

StoryBot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.
